# Child-Safer Spaces — comprehensive implementation bundle

Version 2.0 • 19 October 2026 • General U.S./Canada framework

## Start here

1. Extract the whole ZIP and open **index.html**. No installation or internet connection is needed for the workspace.
2. Read document **02** for the recommendation, **45** for coverage, and **46** for your entity's first steps.
3. Use **Implementation plan** to assign the 34 tasks and record the site's jurisdiction. Correct known hazards through existing safe procedures immediately.
4. Work through **Decision gates**. Task dispositions and evidence references are required; the tool does not grant approvals.
5. Adapt documents and planning registers, then transfer official records to your organization's controlled systems.
6. Export a JSON planning backup regularly. It includes drafts, tasks, gate notes, register rows and saved calculator inputs.

Static handbook and role packs do not include local drafts. Use Download working handbook, Print working handbook, or a current document's controls to include local edits.

## Privacy and persistence

Offline single-user planning only: no login, encryption, shared database, signatures, audit-grade history or access controls. Do not enter child identities, health/claims details, CCTV, witnesses or confidential contracts. Browser storage and exported files are readable by anyone with access. Keep sensitive and official records in approved systems.

Document text autosaves as you type. Task fields save when changed. Register rows save with Save row. Calculator inputs save with Calculate and save inputs. CSV and backup imports validate and preview before replacement. Version 1 backups migrate drafts and notes, reopening gates for review against expanded requirements.

Moving files, changing browser/origin or clearing browser data can separate or erase storage. Back up before moving or upgrading. The standalone file and index.html may have separate storage behavior; export/import transfers work.

## Real-world decisions still required

No pilot site, local legal opinion, approved product, test threshold, signed permission, funding award, insurer concession, ethics approval or effectiveness finding is invented. Local professionals and authorities determine requirements; suppliers and independent reviewers establish evidence; organizations sign and fund commitments. See documents 45 and 48.

Begin assessment, ordinary hazard correction and outreach today. New installations and research activities require their applicable gates.
