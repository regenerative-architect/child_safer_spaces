## Definitions
| Field/measure | Definition | Rule |
| --- | --- | --- |
| Site ID, zone ID | Stable non-identifying facility and area codes | Never reuse codes |
| Fall event | Unintentional coming to rest on the ground, floor or a lower level | One event even if several injuries |
| Cart-related event | Fall from, tip-over of, or entrapment in a shopping cart | Keep separate from floor falls |
| Collision event | Contact with a fixture without a fall | Keep separate; link to a fall ID if both occurred |
| Near miss | Loss of balance or hazard encounter without a defined injury event | Separate from the injury numerator |
| Age band | Under 5; 5–11; 12–17; adult; unknown | No inferred exact age; unknown stays unknown |
| Severity | No reported injury; minor reported; professional assessment reported; serious/hospital reported; unknown | Not a staff medical diagnosis; apply approved coding rules |
| Visitor entries | Measured entrances during the stated period | Not unique persons; document staff exclusions and sensor outages |
| Child entries | Credible measured or estimated child visits | Document sampling and uncertainty; never infer from total visits alone |
| Inspection completion | Completed required checks ÷ scheduled checks | Include missed checks |
| Response times | Detection→isolation, isolation→clean-up, clean-up→reopening | Use timestamps; record unknown detection time as unknown |
## Data flow
Operations records source events in the existing secure system. The data steward removes identifiers, checks duplicates and aligns time windows. The analyst receives approved aggregate data. The steering group receives rates and adverse-condition summaries. Public reports undergo small-cell and re-identification review; the default proposal is to suppress cells below 5 and complementary cells that reveal them, subject to privacy approval. This workspace holds aggregate planning counts only.
## Quality checks
Reconcile incident IDs, exposure periods, duplicate reports and severity updates. Missing data is not zero. Report excluded periods and reasons; audit a sample against secure originals. Keep a revision log. Calculate rates only for matching events and exposure windows.
